# SignalRGB Logitech G316 X 98 Plugin

A community plugin adding full **Logitech G316 X 98** keyboard support to SignalRGB.

## Features
- Complete 98% layout mapping including special characters
- Full 30-segment top lightbar support
- Dynamic priority and age-tracking algorithm to prevent color lag and key freezing on fast effects
- Lightweight execution (~4–5 ms frame time) to stay within the SignalRGB scheduler budget
